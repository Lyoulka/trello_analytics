## Architect Decision
- Question / change: `trello-import-sync` — единое решение по задачам 1.1–1.4, 1.6–1.8, 3.1, 4.1–4.2 (1.5 готово; 2.1 N/A): production Trello client + retry; entity import/upsert; интеграция board actions без rewrite; orchestration/single-flight/scheduler/API; docs outline; validation gates.
- Ambiguities resolved | still open:
  - **Resolved (все 8 must-resolve):**
    1. **Single-flight:** in-process `sync.Mutex` (или эквивалент) **+** ровно один `sync_runs.status='running'`. PG advisory lock в v1 **не** использовать (один процесс, ADR-011). При старте `cmd/server`: orphan reclaim — все `running` → `failed`, `finished_at=now()`, `error_summary` без секретов (`orphaned after process restart`). Повторный start при занятом lock/`running` → **409**.
    2. **Card-actions gaps:** v1 **только board feed** (`BoardActionsImporter`). Per-card `/cards/{id}/actions` **не** вызывать в этом change; в status — warning про sparse card history (spike). Gap-fill — отдельный change.
    3. **Status/start JSON:** см. contracts ниже (фиксированные snake_case имена).
    4. **Config/env:** `TRELLO_API_KEY`, `TRELLO_TOKEN`, `TRELLO_BOARD_ID` (уже spike); добавить `TRELLO_SYNC_INTERVAL` (Go duration, default `15m`, `0` = scheduler off); `TRELLO_ACTIONS_PAGE_SIZE` (int, default `100`, clamp 1…1000). HTTP timeout клиента: **30s** (как сейчас в `trello.New`).
    5. **Retry/backoff:** retryable = `429`, `500`, `502`, `503`, `504`, network/timeout/`context`-independent transport errors; non-retry = `401`/`403`/`404` (сразу fail run). Max **5** attempts/request; exponential base **1s**, ×2, cap **60s**; **full jitter**; на 429 уважать `Retry-After` (секунды), если есть. В коде/комментарии: live 429 в spike = `not_reproduced` — политику не выдавать за подтверждённый лимит Trello.
    6. **Task 1.3 vs 1.5:** orchestration **вызывает** существующий `BoardActionsImporter.ImportBoardActions` / `CommitBoardActionsPage` / `ResourceBoardActions` — **без rewrite**. 1.3 считается выполненным, когда оркестратор после entities вызывает importer и run доходит до естественного конца (пустая страница / `len < PageLimit`, `StoppedEarly=false`) либо падает с ошибкой (cursor не двигается mid-page — уже так).
    7. **`sync_runs.status`:** только CHECK из миграции: `running` | `success` | `failed` | `cancelled`. Insert `running` при захвате single-flight; terminal: `success` (полный прогон без error), `failed` (Trello/DB/permanent API), `cancelled` (shutdown/`ctx` cancel). Счётчики: `processed_count` = обработанные actions (+ опционально entity ops), `created_count` ≈ inserts (RowsAffected), `updated_count` ≈ entity upserts-as-update, `error_count` / `error_summary` — агрегат без key/token/URL с секретами (reuse `trello.RedactURL`).
    8. **Scheduler:** goroutine в `cmd/server` после connect DB; тот же orchestrator, что и `POST /start`; tick по `TRELLO_SYNC_INTERVAL`; graceful shutdown отменяет in-flight sync → `cancelled`.
  - **Still open:** N/A для Worker (multi-instance advisory lock — post-v1).
- API / data contracts:
  - **Порядок импорта (жёстко):** board → lists → members/labels → cards (`filter=all`) → board actions (существующий importer).
  - **Idempotency:** `INSERT … ON CONFLICT (trello_*_id) DO UPDATE` для entities (имя/флаги/`updated_at`); actions — `ON CONFLICT (trello_action_id) DO NOTHING` (уже в `CommitBoardActionsPage`). Cursor `board_actions` только после успешного page commit.
  - **`POST /api/v1/sync/start`** (без auth в этом change; CORS разрешить POST):
    - **202** (допустимо **200**) body: `{ "run_id": "<uuid>" }` — sync **асинхронно** в goroutine (не блокировать HTTP; `WriteTimeout` 15s недостаточен для полного импорта).
    - **409** если уже running: `{ "error": "sync_already_running", "run_id": "<uuid текущего>" }`.
  - **`GET /api/v1/sync/status`** — точная схема:

```json
{
  "board_id": "string",
  "last_success_at": "RFC3339|null",
  "current_run": {
    "run_id": "uuid",
    "status": "running|success|failed|cancelled",
    "started_at": "RFC3339",
    "finished_at": "RFC3339|null",
    "processed_count": 0,
    "created_count": 0,
    "updated_count": 0,
    "error_count": 0,
    "error_summary": "string|null"
  },
  "earliest_action_at": "RFC3339|null",
  "latest_action_at": "RFC3339|null",
  "counts": {
    "cards": 0,
    "lists": 0,
    "members": 0,
    "labels": 0,
    "actions": 0
  },
  "primary_import_incomplete": true,
  "warnings": ["string"]
}
```

  - `current_run`: последний run по `started_at` (включая terminal); если таблицы пусты — `null`.
  - `last_success_at`: `finished_at` последнего `status=success`, иначе `null`.
  - `earliest_action_at` / `latest_action_at`: `MIN/MAX(action_date)` из `card_actions`, иначе `null`.
  - `primary_import_incomplete`: `true`, пока не было ни одного `success` **или** курсор `board_actions` отсутствует / последний actions-phase оборван (`StoppedEarly`/error); после полного успешного прогона entities+actions → `false`.
  - `warnings`: статические/динамические строки без секретов (минимум: возможная неполная глубина board history; card-level feed не используется в v1).
  - **Out of scope API:** `/sync/history`, `/sync/retry`, metrics, Dashboard, auth.
- Cross-repo dependencies:
  - **Worker-go (`trello_analytics_back`):** 1.1 client (typed errors 401/404/429 + members/labels endpoints на базе spike); 1.2/1.4 entity upsert + тесты идемпотентности; 1.3 wire existing importer; 1.6 orchestrator+scheduler; 1.7 handlers; 1.8 retry wrapper; расширить `config.Load`; CORS для POST.
  - **Docs (`trello_analytics_open_spec`):** 3.1 — **добавить** секцию «Operational sync» в `docs/trello-integration.md` (env, порядок, resume, single-flight, retry policy, status fields); **не** переписывать spike-факты §6–7.
  - **Frontend:** нет.
  - **Reuse mandate:** не заменять `BoardActionsImporter`, `CommitBoardActionsPage`, `ResourceBoardActions="board_actions"`.
- Risks (perf / security / ops):
  - Долгий первичный импорт (~3k cards) — только async run + resume; не держать sync в HTTP handler.
  - Orphan `running` после crash — reclaim на старте обязателен.
  - Секреты: credentials только env; логи/status через redact; body Trello truncate.
  - 429 политика гипотетическая — не утверждать rate в docs как факт.
  - Single-process lock недостаточен при нескольких репликах — вне v1.
- ADR / OpenSpec updates required:

  - Новый ADR не требуется (покрыто ADR-011).
  - **3.1** — outline operational sync (см. выше).
  - **4.1–4.2:** gates для Tester — сверка acceptance 1–6; `openspec validate trello-import-sync --store trello-analytics`.
