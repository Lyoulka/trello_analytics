# Change: Управление активностью участников Trello в аналитике

## Why

На графиках и в отчётах появляются участники доски, которых команда не хочет учитывать (наблюдатели, бывшие сотрудники, тестовые аккаунты). В схеме уже есть `members.is_active`, но:

- флаг сейчас перезаписывается из Trello (`deactivated`) при каждом sync;
- нет UI/API для ручного управления;
- аналитика не исключает неактивных из workload, отчётов и графиков.

Нужен продуктовый признак «учитывать в аналитике» с явным UI в таблице участников.

## What Changes

- `members.is_active` = **продуктовый** флаг включения в аналитику (по умолчанию `true` при первом импорте).
- Sync **не** перезаписывает `is_active` при обновлении участника (только `full_name` / `username`).
- API: список участников доски + PATCH `is_active` (Team Lead+).
- Analytics / reports: неактивный участник не попадает в workload и фильтры; его назначения не атрибутируются; карточки, у которых среди текущих исполнителей нет ни одного активного участника, исключаются из метрик отчётов и графиков.
- Frontend: страница/таблица участников Trello с переключателем активности.
- Документация: `docs/api.md`, при необходимости `docs/database.md`.

## Impact

- `trello_analytics_open_spec` — этот change, api/database docs
- `trello_analytics_back` — upsert members, analytics load, REST members
- `trello_analytics_front` — UI участников, навигация
