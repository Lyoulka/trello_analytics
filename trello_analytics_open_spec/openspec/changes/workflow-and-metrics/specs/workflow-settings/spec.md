# Spec Delta

## Purpose

Позволяет администратору или тимлиду сопоставить списки Trello логическим этапам и задать правила start/done, bug labels и пороги для корректного расчёта метрик.

## ADDED Requirements

### Requirement: Сопоставление списков этапам
Система MUST позволять сохранить соответствие списков Trello логическим этапам workflow в БД.

#### Scenario: Сохранение маппинга
- **WHEN** уполномоченный пользователь задаёт logical stage для списка
- **THEN** значение MUST сохраняться и использоваться последующими расчётами

### Requirement: Правила start, done и bug labels
Система MUST хранить, какие этапы означают начало работы, завершение, блокировку и какие метки классифицируют баги.

#### Scenario: Чтение правил
- **WHEN** запрашивается конфигурация workflow
- **THEN** ответ MUST включать start/done/blocked stages и bug label rules

### Requirement: Предупреждение при незаполненном workflow
Если обязательные правила для метрики не заданы, система MUST сигнализировать, что связанные метрики нельзя корректно рассчитать.

#### Scenario: Lead Time без start rule
- **WHEN** правило начала Lead Time не настроено
- **THEN** расчёт Lead Time MUST NOT выдаваться как достоверный без предупреждения о недостающей конфигурации

### Requirement: Аудит изменения конфигурации
Изменение workflow MUST сохранять время изменения и автора (и при реализации snapshot — снимок правил).

#### Scenario: Обновление настроек
- **WHEN** workflow settings обновляются
- **THEN** MUST зафиксироваться `updated_at` и идентификатор обновившего пользователя
