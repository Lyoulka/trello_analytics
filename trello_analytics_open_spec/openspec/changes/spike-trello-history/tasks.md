# Tasks

## Критерии приёмки change

Change готов к archive, когда:

1. Задокументированы проверенные типы/сценарии events и явные «не подтверждено».
2. Описаны пагинация, наблюдаемая глубина истории, поведение архивных карточек.
3. Зафиксированы ограничения API (ошибки, rate limits) без выдуманных фактов.
4. Подтверждён подход к идемпотентности (по action id) и resume на уровне эксперимента.
5. Заполнена матрица «событие → метрика» в `docs/trello-integration.md`.
6. Составлен список ограничений для показа пользователю.
7. Нет analytics engine / Dashboard; секреты не в Git.
